How to play Pengui Doku

Learn the three rules, then use simple deductions to find each penguin. These beginner tips also explain the placement logic behind Queens-style puzzles.

The three Pengui Doku rules

  • One per row and column: each horizontal row and vertical column needs exactly one penguin.
  • One per colored region: each region needs exactly one penguin, even when it crosses several rows or columns.
  • No touching: two penguins cannot share an edge or a corner.

A square is a candidate only while all three rules allow it. An X records a square you have ruled out; it is not another piece to place.

Where should you start a logic puzzle?

Scan the regions before choosing a square. A region with very few possible cells is often more useful than a large open area. Compare its candidates with occupied rows, columns and neighboring penguins. The smallest-looking region is not automatically solved: count the cells still allowed by every rule.

Try asking a specific question: “Which square is forced?” rather than “Which square looks likely?” A useful move removes uncertainty elsewhere on the board.

Three useful deductions for beginners

1. A single remaining candidate is forced

If all but one cell in a region have been ruled out, its penguin must go in that last cell. The same reasoning works for an unfinished row or column. After placing it, revisit every affected area before making the next move.

2. A region can reserve a row or column

Suppose a region's only remaining candidates are in row three. You may not yet know which candidate is correct, but that region's penguin must use row three. Every square in row three outside that region is therefore unavailable. Apply the same idea to a column.

Reverse the question too: if an unfinished row can only place its penguin inside one region, the rest of that region cannot contain another penguin.

3. Check squares that block an entire region

Consider a candidate outside a region that still has two possible cells. If placing a penguin on that candidate would touch both cells, it would leave the region with no legal position. You can rule out that candidate without choosing between the region's two cells. Check every condition carefully; being near just one of the cells is not enough.

A simple solving routine

  1. Inspect the regions with the fewest remaining candidates.
  2. Check unfinished rows and columns for a single possible position.
  3. Look for region-and-row or region-and-column overlaps.
  4. After a placement, exclude its row, column, region and touching neighbors.
  5. Repeat the scan: one deduction may reveal another.

If you get stuck, review the marks around your last placement. A single missed diagonal neighbor can leave a misleading candidate. If two positions still appear possible, compare what each would prevent in the nearby regions instead of tapping at random.

Common questions

Does the whole diagonal have to stay empty?

No. The no-touch rule excludes immediate diagonal neighbors. It does not ban every square along a long diagonal as a chess queen would. The row, column and region rules still apply.

Is this classic number Sudoku?

No. Pengui Doku is a placement puzzle: you find penguins rather than fill cells with digits. The shared idea is reasoning from constraints, but the rules and goal are different.

Can I use hints?

Yes. Hints are available in the game. Some hints and extra chances use rewarded ads when an ad is available. This guide describes logical techniques; it does not promise that the in-game hint explains these techniques.

Why can a smaller board still feel difficult?

Board size is only one source of difficulty. The shape of the regions and how much you can deduce at each step also matter. A large board can offer an obvious starting point, while a smaller one may need a less direct deduction.
